#RFM Customer Segmentation Analysis
##Overview 
End-to-end customer segmentation project
##Skils Used
-Python (pandas, plotly, streamlit)
-Data cleaning & EDA
Customer Segmentation 
Interactive dashboard
##Dataset
UCI Online Retail II — 541,910 transactions (2009–2011)

## Results
- 4,338 customers segmented into 7 groups
- 962 Champions identified
- 643 At-Risk customers flagged for re-engagement

## How to Run
```bash
pip install -r requirements.txt
streamlit run src/dashboard.py
```
